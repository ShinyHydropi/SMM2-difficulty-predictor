# Mario Maker 2 Level Exploration

CSE 330 final project. Pulls Super Mario Maker 2 levels from the [TheGreatRambler/mm2_level](https://huggingface.co/datasets/TheGreatRambler/mm2_level) dataset and parses them into Python objects for use in neural network experiments.

## Files

- `data_pull.py`: streams one level from the dataset, parses it, and prints each overworld object along with the unique tile positions that contain objects
- `level_view.py`: utility that saves a level as `level.bcd` so it can be uploaded to the [level viewer](https://tgrcode.com/level_viewer)
- `level.py`: generated by Kaitai Struct from the level format (do not edit by hand, edit the source `.ksy` file and rebuild)
- `networks/`: placeholder files for the models (`cnn_padding.py`, `cnn_pooling.py`, `lstm.py`, `rnn.py`), currently empty

## Setup

1. Create and activate a virtual environment

```
python -m venv .venv
.venv\Scripts\activate
```

2. Install the dependencies

```
pip install datasets kaitaistruct
```

## Usage

Print the objects in a level:

```
python data_pull.py
```

Export a level to view it:

```
python level_view.py
```

## Notes

- The dataset is streamed, so nothing large is downloaded locally
- Level data is zlib compressed and must be decompressed before parsing
- `level.overworld.objects` is a fixed size array (a Kaitai Struct limitation), so loop up to `object_count` to avoid reading null objects
